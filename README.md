# PAYJURY

**Payment proves the transfer. GenLayer judges the delivery.**

An evidence-first Internet Court application integrating the **x402 HTTP payment protocol** with **GenLayer Intelligent Contracts**. A buyer can inspect a real x402 quote, independently verify a Base USDC transfer, assemble an immutable dispute packet, and submit a case to GenLayer for AI-validator adjudication.

> **Status: under development.** This repository is not a claim of a verified x402 → GenLayer E2E transaction or an official 9.5/10 judge score. Real payments and GenLayer writes are never performed automatically by the public web demo.

**Principles:** pay → dispute → verdict; real evidence only; no OpenServ agent proxy, no automatic replay, no escrow/refunds implied.

See the detailed architecture, acceptance plan and run commands in the forthcoming implementation branch.
